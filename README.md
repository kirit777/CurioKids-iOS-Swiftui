# CurioKids-iOS-Swiftui

CurioKids

A fun and interactive learning adventure for kids featuring animals, space, science, countries, quizzes, voice learning, AR exploration, coloring books, and offline educational packs.

CurioKids is a modern educational app designed to make learning exciting, interactive, and engaging for children.

Kids can explore animals, space, science, countries, plants, vehicles, famous places, and many other fascinating topics through beautiful visuals, interactive lessons, voice-guided learning, quizzes, coloring activities, and immersive AR experiences.

The app supports offline learning packs, allowing children to continue learning even without an internet connection. Parents can monitor progress, manage screen time, enable learning reminders, and create a safe educational environment through the built-in Parent Dashboard.

CurioKids combines education, creativity, and technology to create an unforgettable learning journey that helps children discover, imagine, and grow every day.

Whether your child loves exploring planets, learning animal facts, solving quizzes, drawing colorful artwork, or discovering the world around them, CurioKids transforms learning into an exciting adventure.
